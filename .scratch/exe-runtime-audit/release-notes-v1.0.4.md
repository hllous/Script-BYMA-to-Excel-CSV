## Español

### Agregado

- Menú inicial del ejecutable con opciones para cambiar la carpeta de salida, cerrar la sesión guardada de IOL y salir.
- Navegación desde el menú de instrumentos para volver al menú principal o salir.

### Cambiado

- El formato de salida se elige con **Espacio** y se confirma con **Enter**; solo se permite una opción: CSV, XLSX o ambos.
- Después de exportar se puede volver al selector, al menú principal, cerrar sesión o salir.

### Corregido

- La pantalla final muestra únicamente los CSV/XLSX exportados; las rutas de logs y auditoría permanecen fuera de la salida visible.

### Instalación

1. Descargar `ScriptIOLExcel.exe` y `SHA256SUMS.txt` de los archivos adjuntos a esta release.
2. Comparar el SHA-256 de `ScriptIOLExcel.exe` con `SHA256SUMS.txt`.
3. Esta versión no está firmada digitalmente: verificar que se descargó desde este repositorio antes de continuar ante una advertencia de Windows.
4. Ejecutar `ScriptIOLExcel.exe` y seguir las opciones del menú inicial.

## English

### Added

- Executable startup-menu actions to change the output folder, log out the saved IOL account, and exit.
- Instrument-menu navigation back to the startup menu or out of the program.

### Changed

- Output format is selected with **Space** and confirmed with **Enter**; exactly one option is allowed: CSV, XLSX, or both.
- After exporting, users can return to the picker, the startup menu, log out, or exit.

### Fixed

- The final screen now lists only exported CSV/XLSX files; log and audit paths are kept out of visible output.

### Installation

1. Download `ScriptIOLExcel.exe` and `SHA256SUMS.txt` from this release's assets.
2. Compare the SHA-256 of `ScriptIOLExcel.exe` with `SHA256SUMS.txt`.
3. This version is not digitally signed: verify it came from this repository before proceeding past a Windows warning.
4. Run `ScriptIOLExcel.exe` and use the startup menu options.
