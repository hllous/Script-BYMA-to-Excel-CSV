## Español

### Cambiado

- La acción de cuenta del menú inicial muestra **"Iniciar sesión de IOL"** cuando no hay una cuenta guardada y **"Cerrar sesión de IOL"** cuando sí la hay.
- **Todos** ahora selecciona visualmente todas las categorías disponibles, sin seleccionar Custom. Al desmarcar una categoría, solo se desmarca Todos.
- Las acciones de navegación de los niveles 2 y 3 se ejecutan con Enter y no dejan una marca de selección.

### Instalación

1. Descargar `ScriptIOLExcel.exe` y `SHA256SUMS.txt` de los archivos adjuntos a esta release.
2. Comparar el SHA-256 de `ScriptIOLExcel.exe` con `SHA256SUMS.txt`.
3. Esta versión no está firmada digitalmente: verificar que se descargó desde este repositorio antes de continuar ante una advertencia de Windows.

## English

### Changed

- The startup menu's account action shows **"Iniciar sesión de IOL"** when no account is saved and **"Cerrar sesión de IOL"** when one is saved.
- **Todos** now visibly selects all available categories without selecting Custom. Clearing one category only clears Todos.
- Level-two and level-three navigation actions run with Enter and do not leave a selection checkmark.

### Installation

1. Download `ScriptIOLExcel.exe` and `SHA256SUMS.txt` from this release's assets.
2. Compare the SHA-256 of `ScriptIOLExcel.exe` with `SHA256SUMS.txt`.
3. This version is not digitally signed: verify it came from this repository before proceeding past a Windows warning.
